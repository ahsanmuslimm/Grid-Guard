PHASE 2 COMMANDS

GCP Commands — Run These Now (Phase 2)
While I'm working on Phase 4 (agents are already built) and Phase 5, run these in your terminal in order:

Step 1 — Authenticate:

gcloud auth login
gcloud auth application-default login
Step 2 — Create project + enable APIs:

gcloud projects create gridguard-agent-2026 --name="GridGuard"
gcloud config set project gridguard-agent-2026
gcloud services enable aiplatform.googleapis.com run.googleapis.com cloudbuild.googleapis.com secretmanager.googleapis.com artifactregistry.googleapis.com cloudresourcemanager.googleapis.com iam.googleapis.com logging.googleapis.com monitoring.googleapis.com
Step 3 — Service account:

gcloud iam service-accounts create gridguard-sa --display-name="GridGuard Service Account"
gcloud projects add-iam-policy-binding gridguard-agent-2026 --member="serviceAccount:gridguard-sa@gridguard-agent-2026.iam.gserviceaccount.com" --role="roles/aiplatform.user"
gcloud projects add-iam-policy-binding gridguard-agent-2026 --member="serviceAccount:gridguard-sa@gridguard-agent-2026.iam.gserviceaccount.com" --role="roles/secretmanager.secretAccessor"
gcloud projects add-iam-policy-binding gridguard-agent-2026 --member="serviceAccount:gridguard-sa@gridguard-agent-2026.iam.gserviceaccount.com" --role="roles/run.invoker"
mkdir credentials
gcloud iam service-accounts keys create ./credentials/gcp-key.json --iam-account="gridguard-sa@gridguard-agent-2026.iam.gserviceaccount.com"
Step 4 — Billing alert + bucket:

gcloud storage buckets create gs://gridguard-staging-gridguard-agent-2026 --location=us-central1
Set the $50 billing alert manually in the GCP Console → Billing → Budgets & Alerts.
